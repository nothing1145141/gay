# 可选依赖：缺失不影响基本功能，但会关闭对应特性。
# 手动安装：  pip install rawpy pyopencl onnxruntime
# 注意：package.bat 只安装本文件核心依赖，不会自动装下列可选包。
#
# rawpy        - RAW 解码（DNG/CR2/CR3/NEF/ARW/RW2/RAF/ORF 等，LibRaw）
# pyopencl     - GPU 加速（需显卡驱动自带 OpenCL：NVIDIA / AMD / Intel 均可）
#                仅纯逐像素阶段（白平衡/基础/黑白/曲线/颜色分级）走 OpenCL
# onnxruntime  - 本地分割推理引擎：SAM2.1 像素级蒙版 + u2net + skyseg + yolov8n
#                缺失时本地引擎不可用（segment_local 会抛错提示安装），
#                但 auto.py 的 VLM 网格蒙版引擎不受影响。
#                建议 onnxruntime>=1.16；GPU 版可用 onnxruntime-gpu。
